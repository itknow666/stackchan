# 验证范围

## 此前实机验收

- DeepSeek 语音识别和回复；固定短句触发自定义录音。
- 待机摸头播放本地十句录音，进入 Agent 不再检查更新。
- 傲娇角色回复及表情、摆头联动。
- AI Agent 内同时看到蓝牙转头、张嘴和紫色灯光。
- 调整后，固定录音与较长回复在蓝牙连接时连续播放，用户反馈没有明显卡音。
- 音量控制代码包含设备回读、静音及 NVS 保存；发布时不改变现用音量。

## 尚未完成的实机验证

用户曾报告拔掉电脑 USB 后触屏无法进入 AI Agent，普通充电头也出现同样现象。当前固件已将主日志控制台改为 UART，USB Serial/JTAG 作为辅助输出，避免 USB 主机断开时日志写入异常影响程序。相关诊断是主机复现和固件构建证据，不等同于最终电池供电实机验收。

**电池供电触屏、独立关机后按键冷启动仍待确认。** 在确认前不应把该问题描述为彻底解决；电源管理或硬件因素仍可能需要进一步排查。

没有执行成品发布或生成供他人直接刷写的固件；公开代码不含私人录音。自动检查的结果见仓库 CI；当前这份快照本地执行的结果记录在 `docs/publication-checks.md`。
