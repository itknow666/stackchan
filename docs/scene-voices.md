# 场景语音库

`examples/scene-lines.zh.txt` 提供二十类各十句的中文台词，共二百句，包含任务接收、处理中、完成、失败、取消、连接异常、电脑工作、检查验收、摸头、被夸、吐槽、见面、关心、安慰、鼓励、庆祝、专注、提醒、倾听和告别。文本公开，私人声音不随仓库发布。

每条有稳定 ID、类别、建议表情、台词与明确调用短语。例如 `job_done_01`、`job_failed_01`、`pc_work_01`，以及“播放任务完成第一句”。自动事件必须由真实状态触发，不能根据模型猜测使用“检查通过”等台词。表情字段是调用建议，导入语音不代表已自动接入动作工具。

## 使用已有 GPT-SoVITS 工程生成

本工具只连接本机已运行的 GPT-SoVITS `/tts`，沿用自行配置的模型和参考声音，不下载模型、不购买服务、不上传参考录音。需要已有模型的使用授权。安装生成与校验依赖后，使用自己的私有路径：

```powershell
python -m pip install numpy scipy soundfile faster-whisper
python tools/generate-scene-voices.py --catalog examples/scene-lines.zh.txt --output C:/Private/DaniaScenes --reference C:/Private/reference.wav --prompt-text-file C:/Private/reference.txt --asr-model C:/Private/whisper-model --minimum-score 0.93
```

参考文本必须与参考声音一致。服务器应只监听本机回环地址；先加载正确的模型，再开始生成。默认使用 CUDA，可指定 `--device cpu`。更换模型时使用新的输出目录，避免把不同声音的候选混在一起。

输出包括 WAV、二十四千赫单声道 PCM、调用清单、质量记录、CSV 和可筛选的 `试听.html`。每条检查有效采样、非静音、最长十四点五秒、音量峰值与本地语音识别一致性；低于阈值会换种子重试。仅通过的条目进入可调用清单，失败时整体返回非零退出码。自动识别不等于人工听感验收，尤其需要留意同音字、语气和停顿。

断点续跑会核对输入指纹和已生成文件的哈希；输入改变需使用新目录。质量记录含预期对应的识别结果，仍应保存在私人目录。成功文件不覆盖原有三十一段录音。

## 调用与 SD 包

生成的 `manifest.json` 使用现有云端录音匹配格式。把通过检查的 PCM 与规则合入私有运行包后，对机器人说清单里的完整调用短语即可播放。保留原规则和包身份，新增规则不宣称已经位于设备 SD；没有对应本地资源时继续走网络音频。

当前固件每个 SD 包最多六十四条。二百条新声音应分为四个五十条的导入包；可在每包加入原有十条摸头录音，形成六十条。一次只激活一个包；未激活的资源继续放在电脑或云端，不会因复制多个包就同时可用。替换前备份现用包，不能为存放更多文件而无界增加常驻内存。此批默认不改机器人已有的三十一条 SD 包。

Codex 自动通知使用桥接配置指定的、已实际导入 SD 的录音 ID。整个二百条库可供后续场景选择，但不自动让每个场景获得定时器、电脑操作或家庭控制能力。接入与通知规则见 [Codex 语音任务](codex-voice-tasks.md)。
