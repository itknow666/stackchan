# Codex 语音任务与完成播报 Implementation Plan

**Goal:** 对机器人说明确的 Codex 任务后，电脑后台执行；电脑与机器人连接有效时播报真实终态，另生成二百条私人场景语音供调用。

**Architecture:** 沿用经过认证的云端到电脑连接。新增异步任务启动、状态和取消，保存任务与 Codex 会话关联；任务执行不占用现有十五秒电脑 RPC。完成通知通过现有本机 MQTT/BLE 桥接，检查连接与空闲状态，有限等待且不重复播放。私有声音留在运行目录，公开仅放生成工具、分类台词及协议。

**Tech Stack:** Python asyncio、Codex 官方非交互接口、Go 工具分派、MQTT/BLE、现有 GPT-SoVITS 本地推理、FFmpeg。

## Task 1: 任务桥接及完成通知

Files: `pc-assistant/dania_pc/{config,executor,client,protocol}.py`、新 `codex_tasks.py`；云端 `internal/service/ai` 下现有电脑工具文件；`home-assistant/bridge.py`；相关 tests 与配置示例。

1. 检查官方 Codex 文档及本机支持选项；使用本机安装与登录，不输出认证信息。
2. 为指定项目启动、状态、取消、重复请求、断线、超时及错误终态添加回归测试，使用假进程，避免生成真实修改。
3. 新操作只接受项目 ID 和有界任务文本。Codex 参数数组启动，无 shell 拼接；默认限制项目工作区、禁止自动发布与删除等外部操作，明确执行权限。
4. RPC 快速返回已接收与任务编号，后台有界执行；同一时间一个任务，状态持久化，不自动重跑完成或失联任务。
5. MQTT 通知携带唯一任务标识及真实终态；机器人 BLE 已连接且电脑在线才尝试，保留结果供查询。忙碌时有限等待，未知播放状态不重播。复用已有完成场景录音，错误不说完成。
6. 运行电脑助手、桥接及受影响云端测试、构建；先规格审查，再质量审查，修复后复审。

## Task 2: 二百条语音资源

Files: 新分类台词及生成工具；私有 `D:/桌面文件/？？？/达妮娅互动语音` 下新输出目录。禁止覆盖旧录音。

1. 编写二十类各十句，共二百句独立中文口语，保持角色且区分成功、失败、取消、离线等事实。
2. 沿用现有 GPT-SoVITS 模型和参考素材，本地生成并支持断点续跑；不购买云服务。
3. 检查采样、时长、静音、削波、识别一致性；失败项重试并保留报告，不把未通过项当作完成。
4. 导出 WAV、PCM、调用清单和试听页；SD 导入包分为每包不超过六十四条，保留原三十一条设备包，不为扩容而增大固件常驻内存。
5. 场景资源接入现有云端匹配与控制台；仅公开文本和工具，私人声音不上传 GitHub。

## Final integration

安装已通过检查的电脑助手与桥接，验证语音任务、真实 Codex 最小只读任务完成、终态通知、重复通知不重复播放及离线不误报。记录自动验证和待用户听感验收的区别。公开内容扫描后提交功能分支，保留已有音频候选 PR 的独立状态。
