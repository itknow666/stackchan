# 后续优化

截至二〇二六年十一月十六日，Agent 直启、精简维护、SD 录音、Agent 与蓝牙共存、反向调用有限电脑工具均已有实现。旧独立供电问题与重复打开记事本已获用户确认修复。聊天音频候选版听感已通过，但一次 AFE 看门狗告警尚待定位，详见[验证记录](verification.md)及[草稿 PR #1](https://github.com/itknow666/stackchan/pull/1)。新版本维护页和物理冷启动仍需单独验收。

下一轮按“稳定运行、记住偏好、执行场景、获取必要上下文”的顺序推进，详细设计、用户例句与验收标准见[智能化方案](intelligence-plan.md)。后续能力尚未实现，不因已有打开软件或文件夹工具就视为已有桌面理解或编程能力。

| 顺序 | 目标 | 主要落点 |
| --- | --- | --- |
| 先完成 | 定位 AFE 告警、持续对话验收、明确动作优先权 | 固件与运行诊断 |
| 第一批 | 可查看、纠正和删除的偏好记忆；多步场景和取消 | 云端、电脑助手、控制台 |
| 第二批 | 指定窗口状态验证、选中文本问答、持久提醒与 Home Assistant 场景 | 电脑助手与云端工具 |
| 后续探索 | 指定项目编程助手、按需摄像头快照、唤醒与打断体验 | 独立能力评估后接入 |

长期记忆的主存储放在电脑或云端；SD 用于版本化录音包、缓存和离线反馈。

后续固件发布需要为对应硬件记录 PSRAM 模式、分区布局、配置和校验值，提供可回退方案。公开的演示声音应单独确认授权；个人语音包继续保留在运行环境中。

摄像头恢复、三轴动作和完全离线大模型对话仍未实现。SD 增加存储容量，不增加内部内存或模型推理能力。
