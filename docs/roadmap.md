# 后续优化

旧独立供电、触屏和按键开机问题已由用户确认修复。本批实现 Agent 直接启动、精简维护、SD 录音加载与状态、场景录音本地播放协商，以及语音反向调用有限电脑工具。自动检查和部署记录分别保留，新固件仍需用户确认摸头与长回复听感、维护页操作和断开 USB 后冷启动。

下一批优先做更清楚的动作仲裁，减少自主动作与遥控争抢，再增加可编辑的场景联动、资源包管理和可控的长期记忆。电脑屏幕读取、文件内容读取与调用编程助手属于后续单独设计的能力，不因具备打开项目文件夹就视为已经实现。

后续固件发布需要为对应硬件记录 PSRAM 模式、分区布局、配置和校验值，提供可回退方案。公开的演示声音应单独确认授权；个人语音包继续保留在运行环境中。

摄像头恢复、三轴动作和完全离线大模型对话仍未实现。SD 增加存储容量，不增加内部内存或模型推理能力。
